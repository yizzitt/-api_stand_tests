# API Stand Tests

## Descripción
Proyecto de pruebas automatizadas de API utilizando Python y pytest.

## Tecnologías
- Python
- Pytest
- Requests
- PyCharm

## Estructura del proyecto
- configuration.py: Configuración del proyecto.
- data.py: Datos utilizados en las pruebas.
- sender_stand_request.py: Funciones para realizar solicitudes HTTP.
- create_user_test.py: Pruebas automatizadas de creación de usuarios.

## Ejecución de pruebas

Para ejecutar las pruebas utiliza:

pytest
